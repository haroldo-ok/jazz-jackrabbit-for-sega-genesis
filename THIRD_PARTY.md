# Third-party references

- **OpenJazz** — https://github.com/AlisterT/openjazz — GPL-2.0-or-later.
  Used as a technical reference for gameplay and .0SC/bonus sprite decoding.
  Scene-format code follows OpenJazz's `jj1sceneload.cpp` (AJ Thomson,
  Carsten Teibes); this project is distributed under GPL-2.0-or-later.
- **SGDK** — https://github.com/Stephane-D/SGDK — development library and
  tooling used to build the Genesis ROM. It is an external build prerequisite.
- **Jazz Jackrabbit shareware data** — raw installation not bundled; the repository contains converted game-derived assets.

The project is released under GPL-2.0-or-later to remain suitable for a future
OpenJazz-derived implementation. See `LICENSE`.

- **Jazz soundtrack conversion** — https://github.com/haroldo-ok/convert-s3m-vgm-jazzjackrabbit-md — the existing FM conversion supplies `res/music/endlevel.vgm`; the music itself remains subject to its owners' rights.
